🧭 브레드크럼🃏 순서 변경 리스트🌀 field-sizing

🧭 브레드크럼 — 깊은 경로는 가운데를 접고, 현재 위치는 링크가 아니다 내비게이션

가맹점 > 지점 > 단말기 > 정산 > 상세처럼 깊어지는 경로를 좁은 폭에서도 길 잃지 않게 보여줍니다.

컨테이너 폭을 바꿔 보세요

560px

4단계 이상이면 처음과 마지막 2개만 남기고 가운데를 "…" 메뉴로 접습니다. 마지막(현재) 항목은 aria-current="page".

<nav aria-label="현재 위치"><ol><li><a href="/m">가맹점</a></li>…<li><a aria-current="page">상세</a></li></ol></nav>
핵심: 접힌 항목도 키보드로 도달 가능해야 하고(메뉴 버튼 → 방향키/Tab), 현재 페이지는 클릭 대상이 아니라 위치 표시다.

🃏 순서 변경 리스트 — 드래그는 보너스, 위/아래 버튼이 기본 카드UI

정산 계좌 우선순위처럼 순서가 의미를 갖는 리스트. 드래그만 있으면 키보드·스크린리더 사용자는 못 바꿉니다.

정산 계좌 우선순위 (1순위부터 출금)

    순서를 바꾸면 여기에 안내됩니다.

    버튼 또는 핸들 드래그로 이동. 이동 후 포커스는 같은 항목에 남고, 결과는 aria-live로 읽어 줍니다.

    // 이동: 배열 splice 후 렌더, 포커스 복원
items.splice(to,0,items.splice(from,1)[0]); render(); focusBtn(id,dir); live(`${name} ${to+1}번째로 이동`);
    핵심: 순서 변경은 "이동 → 포커스 유지 → 말로 알림" 세 짝. 맨 위/아래 버튼은 disabled 대신 aria-disabled로 포커스를 잃지 않게 한다.

    🌀 field-sizing: content — 입력창이 내용 길이에 맞춰 스스로 커지기 마이크로인터랙션

    textarea 자동 높이 JS(scrollHeight 계산)를 CSS 한 줄로 대체합니다.

    왼쪽: 고정 / 오른쪽: field-sizing: content

    0자

    인라인 입력: 처럼 글자 수에 맞춰 폭도 변합니다.

    textarea{field-sizing:content;min-height:2.6em;max-height:9em}
    핵심: 지원이 없는 브라우저에서는 그냥 고정 크기로 동작(점진적 향상). 지원 범위는 Chromium 계열 위주로 알려져 있으나 정확한 버전·Safari/Firefox 상태는 배포 전 MDN·caniuse에서 확인 필요 — 추정.
