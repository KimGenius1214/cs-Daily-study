🧭 목록 상태를 주소에 담기 — 필터·정렬·페이지, 그리고 push와 replace 고르기 내비게이션·탭

필터·정렬·페이지를 URL 쿼리(?status=fail&page=2)에 두면 새로고침·링크 공유·뒤로가기가 공짜로 동작합니다. 핵심은 "어떤 변경이 히스토리 한 칸(push)이고, 어떤 변경이 제자리 덮어쓰기(replace)인가"입니다. 아래 주소창은 시뮬레이션이라 실제 이동은 없습니다.

거래 내역 (24건 · 5건씩) — 실제로 만져 보세요

    필터·정렬 변경 = push(+ page 초기화), 페이지 이동 = push, 검색어 타이핑 = 0.4초 뒤 replace(글자마다 히스토리가 쌓이지 않게). 기본값(전체·최신순·1페이지)은 URL에서 생략합니다. 아래 버튼으로 이상한 주소도 넣어 보세요.

    // 읽기: 항상 "허용 목록"으로 정제 (잘못된 값은 기본값)
const STATUS = ['done','fail','wait'] as const;
function parse(sp: URLSearchParams) {
  const status = STATUS.find(s => s === sp.get('status')) ?? 'all';
  const page = Math.max(1, Number(sp.get('page')) || 1);
  return { status, page, sort: sp.get('sort') ?? 'date_desc', q: sp.get('q') ?? '' };
}
// 쓰기: 기본값은 지우고, 필터가 바뀌면 page 리셋
function update(next, mode: 'push' | 'replace') {
  const sp = new URLSearchParams();
  if (next.status !== 'all') sp.set('status', next.status);
  if (next.page > 1) sp.set('page', String(next.page));
  router[mode](`${pathname}?${sp}`, { scroll: false }); // Next.js
}
    Next.js App Router에선 서버 컴포넌트가 searchParams prop으로 같은 값을 바로 읽으니, URL이 곧 "단일 상태 출처"가 됩니다. 타이핑 중 replace는 입력창 자체는 로컬 state로 두고 debounce(입력이 멈출 때까지 기다렸다 실행) 뒤에만 URL에 반영하세요.

    🃏 거래 상세 키-값 목록 — dl로 의미 붙이고, 마스킹·긴 값·복사를 다루기 카드·리스트

dl.kv { display:grid; grid-template-columns:max-content 1fr; gap:0 18px }

    flex/grid 자식은 min-width:0이 없으면 긴 문자열이 줄어들지 않아 말줄임(text-overflow)이 안 먹습니다. 흔한 함정입니다.

    🌀 corner-shape — border-radius에 "곡선의 모양"을 더하는 CSS (스퀴클) 트렌드·개념

    border-radius는 모서리 "크기"만 정합니다. corner-shape는 그 모서리가 원호인지(round), iOS 아이콘 같은 스퀴클(squircle: 사각형과 원 사이의 부드러운 곡선)인지, 깎인 면(bevel)인지 "모양"을 정합니다. 반드시 0이 아닌 border-radius와 함께 써야 보입니다.

    A. 모양 비교 (모두 border-radius: 32px)

    round
    (기본)
    squircle
    bevel
    scoop

    지원 브라우저가 아니면 네 개 모두 같은 둥근 모서리로 보입니다 — 그게 정상적인 폴백입니다.

    B. superellipse(k) 슬라이더

    k = 2

    1 = 원호, 2 = 스퀴클, 0 = 직선 컷, 음수 = 안쪽으로 파인 모서리.

    C. 실제 UI — 점진적 향상 토글

    💳
    결제 카드 관리
    대표 카드 · 신한 1234

    카드·아이콘 칩에만 선택적으로 켭니다. 켜도 레이아웃은 그대로, 모서리 곡선만 달라집니다.

    .card { border-radius: 24px; }          /* 폴백: 모든 브라우저 */
@supports (corner-shape: squircle) {
  .card { corner-shape: squircle; }     /* 지원 시에만 모양 변경 */
}
/* 모서리마다: corner-top-left-shape: bevel; */
    확인한 사실: Chrome/Edge 139부터 지원, Safari·Firefox는 아직(2026-06 기준 외부 글 근거). 아직 Baseline이 아니므로 "없어도 멀쩡한 장식"에만 쓰세요. box-shadow·border와의 상호작용은 직접 확인하지 못해 추정/미검증입니다.
