🔘 길게 눌러 확정 버튼 버튼·액션

되돌릴 수 없는 액션을 모달 없이 "의도적으로 꾹 누르는 동작"으로 확인한다. 마우스·터치·키보드(Space/Enter 누르고 있기) 모두 동작해야 한다.

라이브 — 1.2초간 누르고 있으면 실행, 중간에 떼면 취소

누르고 있는 동안 채워집니다. 떼면 취소. 키보드는 Space/Enter를 누른 채 유지.

금액이 클수록 홀드 시간을 늘린다(예: 2초).

// pointerdown → rAF로 진행률, pointerup/leave/cancel → 취소
btn.addEventListener('pointerdown', start);
['pointerup','pointerleave','pointercancel'].forEach(t => btn.addEventListener(t, cancel));
btn.addEventListener('keydown', e => { if ((e.key===' '||e.key==='Enter') && !e.repeat) start(e) });
btn.addEventListener('keyup', cancel);
btn.addEventListener('contextmenu', e => e.preventDefault()); // 모바일 롱프레스 메뉴 차단
핵심: 홀드만이 유일한 경로면 운동 장애·보조기기 사용자가 막힌다 → 반드시 "클릭 후 확인" 같은 대체 경로를 함께 둔다. 진행 표시는 시각뿐 아니라 aria-live로도 알린다.

⌨️ 수량 스테퍼 입력·폼

+/- 버튼과 숫자 입력을 한 몸으로. 범위 한계에서 버튼 비활성, 직접 입력은 blur 때 보정, ↑↓·PageUp/Down·길게 누르기 가속.

A. 기본 (1~10, 단가 12,000원)

버튼 길게 누르면 반복(점점 빠르게). 입력창에서 ↑↓, PageUp/Down(±5), Home/End.

B. 5단위 상품권 (0~50, step 5)

직접 입력한 7은 blur 때 가까운 5단위(5)로 보정 + 안내.

<input type="text" inputmode="numeric" role="spinbutton"
  aria-valuemin="1" aria-valuemax="10" aria-valuenow="3">
// type=number 대신 text+inputmode: 휠 스크롤로 값이 바뀌는 사고와 'e' 입력 방지
// 한계 도달: 버튼 disabled가 아니라 aria-disabled로 하면 포커스 유지 가능 (여기선 단순화)
핵심: type="number"는 마우스 휠·e/+/- 문자·소수점 로케일 이슈가 있어 금액·수량 입력에는 text+inputmode+spinbutton 조합을 많이 쓴다. 최소/최대 도달 시 버튼 비활성은 스크린리더에 "최소입니다"를 별도로 알려주면 더 좋다(추정: 구현 취향 차이).

🌀 :user-invalid — 건드린 뒤에만 빨개지는 폼 CSS 트렌드·개념

:invalid는 페이지 로드 직후부터 빈 필수 필드를 빨갛게 칠한다. :user-invalid는 사용자가 상호작용(보통 blur/제출 시도)한 뒤에만 매칭된다 — JS 없이 "늦은 에러 표시".

✕ :invalid — 열자마자 빨강

올바른 이메일을 입력하세요
숫자 10자리

✓ :user-invalid — 만진 뒤에만

올바른 이메일을 입력하세요
숫자 10자리
입력하다 다른 칸으로 이동(blur)하면 평가됩니다.
input:user-invalid { border-color: var(--danger); }
input:user-invalid ~ .err { display: block; }
input:user-valid { border-color: var(--ok); }
/* 미지원 브라우저 폴백: @supports not selector(:user-invalid) { ... 기존 JS 방식 } */
핵심: 에러 메시지 노출까지 CSS만으로 가능하지만, 스크린리더에는 aria-invalid/aria-describedby 연결이 별도로 필요하다(CSS 표시만으론 읽히지 않음). 지원 범위는 최신 주요 브라우저에서 널리 지원되는 것으로 알려져 있으나 정확한 버전은 배포 전 MDN/caniuse 확인 필요 — 추정.
