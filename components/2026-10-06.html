🪟 토스트 알림 스택 오버레이·모달·토스트

성공은 짧게, 실패는 오래, 되돌리기 가능한 건 액션을 달아서. 마우스를 올리거나 포커스하면 타이머가 멈춘다.

버튼을 눌러 보세요 (우측 하단에 쌓임, 최대 3개)

성공=role="status"(공손하게 읽기), 실패=role="alert"(즉시 읽기). 진행바가 남은 시간을 보여주고 hover/focus 시 멈춤. Esc로 최신 토스트 닫기.

region: <div aria-live="polite" aria-atomic="false">  // 실패만 role="alert"
timer: pause on mouseenter/focusin, resume on leave
duration: ok 4s · undo 8s · error: 자동 닫힘 없음
핵심: 토스트에 중요한 정보를 단독으로 두지 말 것. 사라지면 못 읽는 사람이 있다(결제 실패는 인라인에도 남기기).

🔔 스켈레톤 로딩 피드백·상태

빠르면 아무것도 보이지 않고(200ms 임계값), 느리면 레이아웃과 같은 모양의 뼈대를, 한 번 보이면 최소 400ms는 유지해 깜빡임을 막는다.

응답 지연을 골라 보세요

❌ 스피너 + 높이 점프

✅ 스켈레톤 + 고정 높이

대기 중
const show = setTimeout(()=>box.innerHTML=skeleton, 200)   // 임계값
await fetch(); clearTimeout(show)
// 이미 보였다면 최소 400ms 유지 후 교체
box.setAttribute('aria-busy','true')  // 완료 시 false
핵심: 스켈레톤은 실제 행과 같은 높이(min-height)로 그려야 CLS(누적 레이아웃 이동)가 안 생긴다. 왼쪽은 도착 순간 목록이 아래를 밀어낸다.

🌀 dialog closedby — 바깥 클릭 닫기를 속성으로 트렌드·개념

closedby는 dialog를 어떻게 닫을 수 있는지 선언한다: any(바깥 클릭·Esc), closerequest(Esc만), none(버튼만).

세 값을 비교

결제 취소 확인

<dialog closedby="closerequest">  <!-- 결제 확인처럼 실수로 닫히면 안 되는 곳 -->
if (!('closedBy' in HTMLDialogElement.prototype)) { /* 클릭 핸들러 폴백 */ }
지원 범위: Chromium·Firefox 최신판은 지원, Safari는 미확인 — 추정. 위 데모는 미지원이면 JS 폴백으로 동작하며 결과 표시줄에 구분해 보여줌. 배포 전 caniuse·MDN 확인 필요.
모달 dialog 기본값은 closerequest. 결제·파괴적 확인은 none/closerequest, 가벼운 미리보기는 any.
