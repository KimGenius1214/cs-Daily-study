표 안 막대 — 숫자는 막대 밖에 두고, 축은 필터해도 고정, 음수는 0에서 반대로 📊 데이터·테이블·차트

가맹점별 매출 표에 셀 안 막대(데이터 바)를 넣으면 "누가 큰지"가 한눈에 보입니다. 다만 막대 위에 숫자를 겹치면 읽기 어렵고, 필터할 때마다 막대 길이 기준이 바뀌면 같은 금액이 다르게 보이며, 환불이 더 큰 가맹점(음수)을 길이로만 그리면 오해를 부릅니다.

라이브 — 정렬·필터·옵션을 바꿔 보세요

11월 가맹점별 매출 (단위: 원)

✔ 숫자는 고정폭 숫자(tabular-nums)로 오른쪽 정렬, 막대는 그 옆 별도 칸 — 막대는 aria-hidden이라 낭독기는 숫자만 읽습니다.

✔ "축 고정"을 끄고 필터를 켜 보세요. 가장 큰 행이 다시 100%가 되어 작은 가맹점이 갑자기 커 보입니다.

✔ 순매출은 가운데 0선에서 좌우로 갈라지는 발산형(diverging) 막대 — 음수는 빨강 + 빗금 + 숫자 앞 −기호까지, 색 하나에 기대지 않습니다.

막대 기준(최대값)을 "전체"로 둘지 "보이는 행"으로 둘지는 질문에 달렸습니다. "전체 중 어디쯤인가"가 궁금하면 고정, "이 중에서 누가 큰가"만 보면 재계산이 맞습니다. 어느 쪽이든 표 아래에 기준을 글로 적어 두는 것이 핵심입니다(위의 회색 문구).

결제 완료 화면 — 무엇이 끝났는지 먼저, 뒤로가기·새로고침이 다시 결제를 부르지 않게 🔔 피드백·상태

완료 화면은 "축하 애니메이션"보다 금액·수단·승인번호와 다음 행동이 먼저입니다. 그리고 이 화면에서 뒤로가기를 누르면 결제 페이지가 다시 열리고, 새로고침하면 결과가 날아가거나 요청이 다시 가는 문제가 흔합니다.

    Intl.RelativeTimeFormat — "3분 전·어제"를 직접 문자열로 만들지 않고, 기준은 달력 날짜로 🌀 트렌드·개념

    Intl.RelativeTimeFormat은 "3분 전", "2시간 후", "어제" 같은 상대 시각 문구를 언어에 맞게 만들어 주는 내장 API입니다. 다만 어떤 단위로 보여줄지는 직접 정해야 하고, "어제"를 24시간 차이로 계산하면 자정 근처에서 틀립니다.

    라이브 — 지금 시각을 움직이고 옵션을 바꿔 보세요

    기준 "지금"(KST):

    이벤트상대 표시 (달력 기준)24시간 나눗셈

      ✔ 상대 표시에 마우스를 올리면 정확한 시각(KST)이 보입니다 — <time datetime>에 원본 ISO 시각을 같이 담았습니다.

      ✔ 빨간 오른쪽 칸: 경과 시간을 24시간으로 나눠 "1일 전/어제"를 고르면 생기는 오차. 오늘 00:20에 그제 22:20 이벤트를 보면 26시간 차이라 나눗셈으로는 "어제"(1일)지만, 달력으로는 이틀 전(그저께)입니다. 6시간 미만은 두 방식 모두 "n시간 전".

      ✔ 목록 문구는 30초마다 다시 계산되지만 aria-live가 아닙니다 — 낭독기가 몇십 초마다 "4분 전"을 떠들지 않게.

      const rtf = new Intl.RelativeTimeFormat('ko', { numeric: 'auto' });
rtf.format(-3, 'minute');  // "3분 전"
rtf.format(-1, 'day');     // "어제"   (numeric:'always'면 "1일 전")
rtf.format(0, 'second');   // "지금"

const KST = 9 * 3600_000, DAY = 86_400_000;
const dayKey = (t: number) => Math.floor((t + KST) / DAY);   // KST 달력 날짜 번호

export function relTime(t: number, now = Date.now(), cutDays = 7) {
  const s = Math.round((t - now) / 1000);                  // 음수 = 과거
  if (Math.abs(s) < 45)    return rtf.format(0, 'second');
  if (Math.abs(s) < 3600)  return rtf.format(Math.round(s / 60), 'minute');
  const dDays = dayKey(t) - dayKey(now);                   // ← 24h 나눗셈이 아니라 달력 차이
  if (dDays === 0 || Math.abs(s) < 6 * 3600) return rtf.format(Math.round(s / 3600), 'hour');
  if (Math.abs(dDays) < cutDays) return rtf.format(dDays, 'day');
  return new Intl.DateTimeFormat('ko-KR', { timeZone: 'Asia/Seoul', dateStyle: 'medium' }).format(t);
}

// 마크업: 상대 문구 + 기계가 읽는 원본 + 정확한 시각 툴팁
// <time datetime="2026-11-19T14:50:00Z" title="2026. 11. 19. 오후 11:50">어제</time>
