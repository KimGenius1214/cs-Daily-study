💳 결제 수단 선택 — 기본값·만료·수수료 결제

수단 선택은 "라디오 그룹 + 각 줄에 결정에 필요한 한 줄 정보"가 핵심이다. 만료 카드는 숨기지 말고 이유와 해결 경로를 같이 보여준다.

① 목록 모드   ② 요약 + 변경 모드 (결제 금액 ₩52,000)

① 목록 모드

결제 수단
신한 ···· 1234 선택됨

비활성 라디오는 포커스가 안 가므로 만료 이유를 텍스트로 붙이고, 해결 버튼은 줄 안에 둔다.

② 요약 + 변경 모드

신한 ···· 1234
마지막으로 쓴 수단

재방문 사용자는 "마지막 수단 + 변경"이 클릭 수가 적다. 변경 시 포커스는 선택된 항목으로 돌려준다.

<fieldset><legend>결제 수단</legend>
  <label class="m"><input type="radio" name="pm" value="card1" checked> 신한 ···· 1234 </label>
</fieldset>
.m:has(input:checked){border-color:var(--brand)}
버튼 라벨에 선택한 수단과 금액이 같이 나오면 "무엇으로 얼마를 내는지"를 마지막에 다시 확인시켜 준다.

⌨️ 인증번호 입력 — 칸 나누기 vs 한 칸 입력·폼

6자리 인증번호는 붙여넣기·SMS 자동 채움·자동 이동·재전송 타이머가 한 묶음이다. (테스트용 정답 코드: 123456)

① 칸 나누기 (자동 이동·붙여넣기 분배)   ② 한 칸 입력 (단순·견고)

① 칸 나누기

인증번호 6자리

남은 시간 03:00 ·

6자리를 입력하면 자동으로 확인해요

② 한 칸 입력

문자로 온 6자리 숫자를 입력하세요. 붙여넣기·자동 채움 모두 동작해요.

대기 중
<input inputmode="numeric" autocomplete="one-time-code" maxlength="6" pattern="[0-9]{6}">
칸 나누기는 시각적으로 익숙하지만 자동 채움·IME·스크린리더에서 깨지기 쉽다. 한 칸 + letter-spacing이 더 견고하다.

🌀 text-wrap — balance와 pretty 트렌드

제목·토스트·에러 문구에서 마지막 줄에 한두 글자만 덜렁 남는 현상을 CSS 한 줄로 줄인다. 아래 슬라이더로 너비를 바꿔 보자.

브라우저 지원 확인 중…
h1,h2,.toast-title{ text-wrap: balance; }   /* 제목·짧은 문구 */
p{ text-wrap: pretty; }                      /* 본문: 마지막 줄 고아 방지(브라우저별 차이) */
.ko{ word-break: keep-all; }                 /* 한글 단어 단위 줄바꿈 */
balance는 몇 줄 이하 문구용(브라우저가 줄 수 제한을 둠). pretty의 지원 범위는 브라우저마다 달라 추정/확인 필요 — 안 되어도 깨지지 않는 점진적 향상이다.
