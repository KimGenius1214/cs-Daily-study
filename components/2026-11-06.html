📊 직접 라벨 차트 범례 대신 선 끝 이름 · 색 외 구분

결제수단별 일 거래액(만 원, 가짜 데이터). 범례를 오가며 색을 맞춰 보게 하지 말고, 선 끝에 이름을 직접 붙이고 색 외에 마커·점선으로도 구분한다.

A. 범례 방식 (색에만 의존)

색 4개를 범례와 대조해야 한다. 색각 이상·흑백 인쇄에서 선이 서로 섞인다.

B. 직접 라벨 + 마커/점선 (권장)

선에 마우스를 올리거나 Tab으로 이동하면 해당 선만 강조된다. 아래 칩으로도 고를 수 있다.

데이터 표로 보기 (스크린리더·정확한 값)
/* Okabe-Ito 팔레트: 색각 이상에서도 구분되도록 고안된 8색 중 일부 */
--c1:#0072B2; --c2:#E69F00; --c3:#009E73; --c4:#CC79A7;
/* 색 + 마커 모양 + 선 모양을 함께 */
<g class="ser" tabindex="0" role="img" aria-label="간편결제: 7일 평균 412만 원">
핵심: 이름은 선 끝에 직접, 구분은 색 한 가지에 의존하지 않기, 정확한 값은 표로 제공.

🔔 자동 갱신 패널 마지막 갱신 · 탭 숨김 시 중지 · 실패 시 오래됨 표시

대시보드 숫자가 스스로 갱신될 때 "지금 값이 얼마나 신선한지"를 보여 주는 패턴. 데모의 폴링 주기는 6초(실제 서비스에선 30~60초 등).

탭을 다른 곳으로 전환하면 폴링이 멈추고, 돌아오면 즉시 한 번 갱신한다.

스크린리더: 폴링마다 읽어 주면 소음이다. 수동 새로고침 결과와 "오래됨" 전환만 role=status로 알린다.
실패 처리: 값을 지우지 않고 마지막 값 + "N분 전 기준"을 유지한다. 흰 화면보다 낫다.
document.addEventListener('visibilitychange', () => {
  if (document.hidden) stopPolling(); else { refresh(); startPolling(); }
});

🌀 Intl.DurationFormat 기간을 로케일에 맞게 포맷

"2시간 30분"처럼 기간(duration)을 문자열로 만드는 내장 API. 직접 만든 시·분·초 조합 함수를 대체한다. 지원 여부를 감지해 폴백을 둔다.

라이브 데모

정산 입금까지 남은 시간 (digital, 1초마다 갱신)

--:--:--

초 단위로 바뀌는 숫자는 aria-live를 달지 않는다(매초 읽힘). 대신 라벨에 목표 시각을 텍스트로 병기한다.

const df = new Intl.DurationFormat('ko', { style: 'long' });
df.format({ hours: 2, minutes: 30 });   // "2시간 30분"
new Intl.DurationFormat('ko', { style: 'digital' }).format({ hours: 2, minutes: 5, seconds: 9 });
// 지원 감지: typeof Intl.DurationFormat === 'function'
