🧭 드롭다운 내비게이션🃏 KPI 증감 카드🌀 hidden="until-found"

🧭 드롭다운 내비게이션 — role="menu" 말고 "펼침 버튼 + 링크 목록" 내비게이션·탭

사이트 상단 메뉴의 하위 목록은 앱 메뉴(role=menu)가 아니라 disclosure(버튼이 아래 영역을 펼치고 접는 패턴)입니다. 버튼은 aria-expanded만, 안쪽은 평범한 <a> 목록. Tab으로 그대로 지나가고, Esc는 닫고 버튼으로 돌아갑니다.

A. 데스크톱 — 클릭으로 열기(기본) + 선택적으로 호버 의도 지연

  • 홈
    • 거래내역승인·취소 조회
    • 부분취소금액 일부 환불
    • 결제링크링크·QR 발급
    • 정산내역입금 예정·완료
    • 정산계좌계좌 변경·예금주 확인
    • 기본정보
    • 직원 권한
    • API 키

호버로 열린 상태에서 버튼을 클릭하면 닫히지 않고 "고정"됩니다. 호버가 먼저 열어 놓은 걸 클릭이 다시 닫아버리는 흔한 버그(열리자마자 닫힘)를 막는 처리입니다.

B. 좁은 화면 — 같은 마크업을 아코디언처럼 흐름 안에서 펼치기

  • 홈
    • 거래내역
    • 부분취소
    • 결제링크
    • 정산내역
    • 정산계좌

모바일엔 호버가 없으니 클릭 전용. 여러 개 동시에 열어 둬도 되도록(비교하며 고르기) 여기선 "하나만 열기"를 끕니다.

<nav aria-label="관리자 메뉴">
  <ul>
    <li>
      <button type="button" aria-expanded="false" aria-controls="m-pay">결제</button>
      <ul id="m-pay" hidden>
        <li><a href="/payments" aria-current="page">거래내역</a></li>
        <li><a href="/payments/cancel">부분취소</a></li>
      </ul>
    </li>
  </ul>
</nav>
<!-- role="menu"/"menuitem" 금지: 스크린리더가 앱 메뉴 모드로 바뀌어 Tab 대신 화살표를 강요 -->

닫는 조건 4가지: 같은 버튼 재클릭 · Esc(포커스는 버튼으로) · 포커스가 nav 밖으로 나감(focusout) · nav 바깥 클릭. 화살표 키 이동은 APG 예제에서 "선택 사항"으로 둡니다 — 넣더라도 Tab 순서를 대신하면 안 됩니다.

🃏 KPI 증감 카드 — 색만으로 말하지 않고, 지표마다 "좋은 방향"이 다르다 카드·리스트

대시보드 숫자 카드에서 흔한 실수 세 가지: ① 오르면 무조건 초록 ② 비율 지표를 상대 %로 표시(환불률 1.2→1.8%를 "+50%") ③ 전기간 0일 때 "∞%". 비교 기준(전일·전주 같은 요일)도 카드에 적어야 숫자가 뜻을 가집니다.

비교 기준

좋은 구현 권장

↑/↓ 기호 + "증가/감소" 단어 + 좋음/주의 배지로 색각 이상·흑백 인쇄에서도 읽힙니다. 환불률은 %p(퍼센트포인트 = 비율끼리의 단순 차이), ±0.5% 미만은 "보합"으로 소음을 줄입니다.

흔한 구현 피할 것

"전일"에서 해외카드 결제가 +Infinity%, 환불률 상승이 초록 +50.0%로 보입니다. 숫자는 맞는데 해석이 틀리게 유도됩니다.

type Polarity = 'up-good' | 'down-good' | 'neutral';
function delta(cur: number, prev: number, kind: 'amount' | 'rate', pol: Polarity) {
  if (prev === 0) return cur === 0 ? { tone: 'flat', text: '변동 없음' } : { tone: 'new', text: '신규' };
  const raw = kind === 'rate' ? cur - prev : ((cur - prev) / prev) * 100;   // rate → %p
  const flat = kind === 'rate' ? Math.abs(raw) < 0.05 : Math.abs(raw) < 0.5;
  if (flat) return { tone: 'flat', text: '보합' };
  const up = raw > 0;
  const good = pol === 'neutral' ? null : (up === (pol === 'up-good'));
  const unit = kind === 'rate' ? '%p' : '%';
  return { tone: good === null ? 'flat' : good ? 'good' : 'bad',
           text: `${Math.abs(raw).toFixed(1)}${unit} ${up ? '증가' : '감소'}`, arrow: up ? '▲' : '▼' };
}

반올림 주의: 계산은 원 단위 원본으로 하고 표시만 반올림. "전월 같은 날"은 31일이 없는 달에서 기준일이 사라집니다 — 말일로 당기는지, 비교 불가로 두는지 정책을 먼저 정하세요.

🌀 hidden="until-found" — 접어 둔 내용도 Ctrl+F가 찾아서 펼치게 트렌드·개념

아코디언·"더 보기"로 접은 내용은 보통 hidden(=display:none)이라 브라우저 찾기에 안 걸립니다. hidden="until-found"는 화면에선 숨기되 찾기·텍스트 조각 링크(#:~:text=)로 매칭되면 브라우저가 속성을 지우고 beforematch 이벤트를 쏴 줍니다. 그때 버튼의 aria-expanded만 맞춰 주면 됩니다.

지원 확인 중…이 페이지를 새 탭으로 열고 Ctrl+F → "부분취소" 또는 "영업일"을 검색해 보세요.

hidden="until-found" 찾기에 걸림

네. 거래내역에서 부분취소를 누르고 금액을 입력하면 됩니다. 남은 금액은 다시 부분취소할 수 있어요.
승인일로부터 2영업일 뒤 등록된 정산계좌로 입금됩니다(예시 정책).
가맹점 설정에서 해외카드 결제를 켜면 됩니다. 수수료는 국내카드와 다릅니다.

일반 hidden 찾기에 안 걸림

네. 거래내역에서 부분취소를 누르고 금액을 입력하면 됩니다. (일반 hidden 버전)
승인일로부터 2영업일 뒤 입금됩니다. (일반 hidden 버전)
입력하면 일치하는 항목을 펼칩니다. 
<button aria-expanded="false" aria-controls="a1">결제를 일부만 취소할 수 있나요?</button>
<div id="a1" hidden="until-found">네. 거래내역에서 부분취소를…</div>

<script>
a1.addEventListener('beforematch', () => btn.setAttribute('aria-expanded', 'true')); // 브라우저가 hidden 제거
function toggle(open) {
  btn.setAttribute('aria-expanded', String(open));
  open ? a1.removeAttribute('hidden') : a1.setAttribute('hidden', 'until-found');
}
</script>

/* ⚠️ 전역 리셋 함정: 이 한 줄이 until-found를 죽입니다 */
[hidden] { display: none !important; }              /* ✗ */
[hidden]:not([hidden="until-found"]) { display: none !important; } /* ✓ */

지원: Chrome·Edge 102+, Firefox 139+(2025년 5월). Safari는 작성 시점 미지원으로 알려짐(추정) — 미지원 브라우저에선 그냥 hidden처럼 동작하니 손해는 없고, 위 같은 페이지 내 검색 폴백을 함께 두면 안전합니다.

React에선 hidden="until-found"를 문자열로 넘겨야 합니다(불리언 true로 넘기면 일반 hidden). 버전에 따라 이 값이 그대로 렌더되는지 확인 필요(추정) — 안 되면 ref로 setAttribute.
