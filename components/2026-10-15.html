🧭 탭 — URL 동기화·수동 활성화·넘칠 때의 힌트 내비게이션·탭

새로고침·공유·뒤로가기에서도 같은 탭이 열려야 하고, 무거운 패널은 화살표 이동만으로 로드하면 안 됩니다.

A. 자동 활성화 + 해시 동기화 (가벼운 패널)

이번 달 정산 예정 ₩12,480,000
거래 128건 (승인 120 · 취소 8)
환불 대기 3건

←→로 이동하면 즉시 전환, 주소 해시(#tab=…)도 바뀜. 뒤로가기로 복원.

B. 수동 활성화 (무거운 패널) + 오버플로 페이드

일별 매출 차트 (로드 완료)
←→는 포커스만, Enter/Space로 열기

화살표는 포커스만 이동 → Enter/Space에서 로드(0.6초 가짜 지연). 좁으면 가장자리 페이드.

핵심: aria-selected+roving tabindex, 선택은 URL이 단일 출처, 무거운 패널은 manual activation.
const tabs=[...list.querySelectorAll('[role=tab]')];
function select(t,{focus=true,push=true}={}){
  tabs.forEach(x=>{const on=x===t;x.setAttribute('aria-selected',on);x.tabIndex=on?0:-1;
    document.getElementById(x.getAttribute('aria-controls')).hidden=!on});
  if(push)history.replaceState(null,'','#tab='+t.dataset.key); if(focus)t.focus();}
list.addEventListener('keydown',e=>{const i=tabs.indexOf(document.activeElement);
  const k={ArrowRight:i+1,ArrowLeft:i-1,Home:0,End:tabs.length-1}[e.key]; if(k==null)return;
  e.preventDefault(); const t=tabs[(k+tabs.length)%tabs.length]; auto?select(t):t.focus();});

.card{position:relative}
.card a.stretch::after{content:"";position:absolute;inset:0}
.card .acts{position:relative;z-index:1}
.card:has(a.stretch:focus-visible){outline:3px solid var(--ring)}

🌀 scroll-state 컨테이너 쿼리 — 스크롤 상태를 CSS가 안다 트렌드·개념
