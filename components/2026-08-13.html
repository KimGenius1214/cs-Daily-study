🧭 스크롤 스파이 내비게이션 — 현재 보는 섹션 자동 하이라이트 내비게이션·탭

긴 문서·설정 페이지에서 "내가 지금 어디 있는지"를 왼쪽 목차가 실시간으로 알려주는 패턴. 아래 회색 영역을 스크롤하면 왼쪽 항목의 하이라이트가 따라 움직이고, 항목을 클릭하면 해당 섹션으로 부드럽게 이동한다. 스크롤 이벤트를 직접 계산하지 않고 IntersectionObserver로 감지한다.

  • 👤 계정
  • 💳 결제 수단
  • 🔔 알림
  • 🔒 보안

👤 계정

이름, 이메일, 프로필 이미지를 관리합니다. 이메일 변경 시 인증 메일이 발송됩니다.

연결된 소셜 로그인(구글·애플)을 해제하거나 추가할 수 있습니다.

계정 언어와 시간대를 설정하면 영수증·알림 시각이 그에 맞춰 표시됩니다.

💳 결제 수단

등록한 카드·계좌를 확인하고 기본 결제 수단을 지정합니다.

카드 번호는 마지막 4자리만 노출되고 나머지는 마스킹됩니다.

정기결제에 사용 중인 수단은 삭제 전 대체 수단 지정을 요구합니다.

🔔 알림

결제 완료, 정산, 마케팅 알림을 채널(앱·이메일·문자)별로 켜고 끕니다.

야간 방해금지 시간대를 지정하면 그 시간엔 푸시가 묶여 아침에 요약됩니다.

중요 보안 알림은 끌 수 없도록 잠겨 있습니다.

🔒 보안

비밀번호 변경, 2단계 인증(OTP), 로그인 기기 목록을 관리합니다.

의심스러운 로그인이 감지되면 이 화면 상단에 배너로 표시됩니다.

계정 삭제는 되돌릴 수 없으므로 재인증을 거칩니다.

왜 이렇게? — 활성 항목엔 aria-current="true"를 줘서 스크린리더도 "현재 위치"를 읽는다. 색만으로 구분하지 않고 왼쪽 막대·굵기까지 함께 바꿔 색맹 사용자도 구분되게 했다.

핵심 패턴

  • 스크롤 위치는 scroll 이벤트로 매 프레임 계산하지 말고 IntersectionObserver로 "지금 화면에 들어온 섹션"만 콜백 받는다(성능·배터리 유리).
  • rootMargin을 위쪽으로 당겨(예: 상단 40% 지점) "제목이 상단에 닿는 순간"을 활성 기준으로 삼는다.
  • 목차 클릭 → scrollIntoView({behavior:"smooth"}). 활성 표시는 관찰자가 알아서 갱신하므로 클릭 핸들러에서 색을 직접 바꾸지 않는다(상태 출처 하나로 통일).
용어: IntersectionObserver = 어떤 요소가 화면(또는 스크롤 컨테이너)에 얼마나 들어왔는지를 비동기로 알려주는 브라우저 API. 스크롤 계산을 대신 해준다. · aria-current = 여러 항목 중 지금 활성/현재인 것을 보조기술에 알리는 ARIA 속성.

🃏 선택형 리스트 + 벌크 액션바 — 다중 선택·전체선택·되돌리기 카드·리스트

정산 내역·메일함처럼 "여러 개를 골라 한 번에 처리"하는 리스트. 하나라도 고르면 아래에서 액션 바가 올라오고, 헤더 체크박스는 부분선택일 때 중간(indeterminate) 상태가 된다. 삭제하면 사라지되 토스트의 되돌리기로 3초 안에 복구된다.

0개 선택

왜 이렇게? — 선택된 행은 테두리·배경까지 바꿔 :has(input:checked) CSS 한 줄로 강조(JS 없이). 액션 바는 필요할 때만 올라와 평소 화면을 어지럽히지 않는다.

핵심 패턴

  • 헤더 체크박스는 3상태: 전부 선택=체크, 일부만=indeterminate, 없음=해제. 이 중간 상태는 CSS로는 못 만들고 JS로 el.indeterminate=true를 줘야 한다.
  • 파괴적 액션(삭제)은 즉시 지우되 낙관적 처리 + 되돌리기: 화면에서 먼저 빼고 3초 토스트를 주면, 확인 모달보다 흐름이 덜 끊긴다.
  • 행 강조는 상태(:checked)에서 파생 — 클릭 때마다 클래스를 손으로 토글하지 않는다.
용어: indeterminate = 체크박스의 "일부만 선택됨"을 나타내는 중간 상태(시각적으로 대개 줄표). · 낙관적 UI(optimistic) = 서버 응답을 기다리지 않고 성공을 가정해 화면을 먼저 바꾸고, 실패하면 되돌리는 방식. · :has() = 자식·상태를 조건으로 부모를 선택하는 CSS 관계 선택자.

🌀 Popover API — popover 속성으로 만드는 네이티브 팝오버 트렌드·개념

메뉴·툴팁·힌트를 띄우려고 z-index 싸움·바깥 클릭 감지·ESC 처리를 매번 손으로 짜던 시대가 끝났다. HTML popover 속성 하나면 브라우저가 최상위 레이어에 띄우고, 바깥 클릭·ESC로 닫아준다(라이트 디스미스). 아래 버튼들을 눌러 보라 — 바깥을 클릭하거나 Esc를 누르면 저절로 닫힌다.

정산 상태란?

‘대기’는 심사 중, ‘완료’는 입금 예정, ‘보류’는 확인 필요 상태입니다. 바깥을 누르거나 Esc로 닫으세요.

왜 이렇게? — popovertarget만 연결하면 JS 없이 열고 닫힌다. 여기선 메뉴를 트리거 옆에 붙이려 위치만 JS로 잡았다(정렬 자체는 브라우저가 top-layer로 처리).

지원 확인 중…

왜 지금 뜨나 / 어디에 쓰나

  • 2025년 4월 Baseline 안정(Widely available) — Chrome·Edge·Firefox·Safari 최신에서 폭넓게 동작. 이제 프로덕션에서 라이브러리 없이 써도 되는 단계.
  • 브라우저가 top layer(z-index 최상위)에 올려줘 overflow:hidden·부모 transform에 잘리지 않는다. 오랜 드롭다운 잘림 문제 해결.
  • popover="auto"는 바깥 클릭·ESC로 닫히고 같은 그룹은 하나만 열림(라이트 디스미스). popover="manual"은 코드로만 닫음(예: 단계 안내 툴팁).
  • 쓸 곳: 행 작업 메뉴, 필터 드롭다운, 툴팁·도움말, 알림 목록, 간단한 확인 팝오버. 복잡한 폼·강제 상호작용은 여전히 <dialog> 모달이 적합.
<!-- JS 0줄: 버튼이 팝오버를 토글 -->
<button popovertarget="menu">메뉴</button>
<div id="menu" popover> ... </div>

/* 열렸을 때만 적용되는 상태 선택자 */
#menu:popover-open { display: block; }
#menu::backdrop  { background: rgba(0,0,0,.35); }  /* 뒤 배경 */
용어: top layer = 문서 위에 따로 쌓이는 최상위 렌더 레이어. 팝오버·모달이 여기 올라가 다른 요소에 안 가려진다. · 라이트 디스미스(light dismiss) = 바깥을 클릭하거나 Esc를 누르면 저절로 닫히는 동작. · Baseline(Widely available) = 주요 브라우저에서 충분히 오래 지원돼 안심하고 쓸 수 있는 상태.
