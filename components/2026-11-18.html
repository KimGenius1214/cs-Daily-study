"보유 12,345P"만 보여주면 사용자는 다 쓸 수 있다고 생각합니다. 실제 한도(최소 보유·사용 단위·최소 결제금액)를 입력칸 바로 아래 숫자로 보여주고, 넘치게 입력하면 칸을 떠날 때 맞춘 뒤 맞춘 이유를 문장으로 남깁니다.

// 한도 계산은 한 곳에서 (정수 원 단위만 다룸)
function pointLimit({ balance, order, minHold = 1000, unit = 10, minPay = 0 }) {
  if (balance < minHold) return { usable: false, max: 0, reason: `${minHold.toLocaleString()}P부터 사용 가능` };
  const cap = Math.min(balance, Math.max(0, order - minPay));
  return { usable: true, max: Math.floor(cap / unit) * unit };
}
// blur 시: 맞추고, 맞춘 이유를 말한다
function settle(raw, lim) {
  const n = Number(String(raw).replace(/[^\d]/g, '')) || 0;
  if (n > lim.max) return { value: lim.max, msg: `최대 ${lim.max.toLocaleString()}P까지 쓸 수 있어 맞췄어요` };
  const v = Math.floor(n / 10) * 10;
  if (v !== n) return { value: v, msg: `10P 단위로 써요 — ${n - v}P는 남겨 둘게요` };
  return { value: v, msg: '' };
}
핵심: ① 한도는 "보유"가 아니라 "이번 주문 최대"로 보여준다 ② 사용 불가면 칸을 숨기지 말고 이유와 함께 비활성 ③ 최종 금액이 0원이면 결제 수단 영역을 비활성·안내로 바꾸고 버튼 문구도 바꾼다 ④ 서버가 같은 공식으로 다시 검증한다(클라이언트 값은 제안일 뿐).

웹훅 URL 입력 — URL 파서로 정규화하고, 못 받는 주소는 저장 전에 막고, 테스트 전송이 성공해야 저장 ⌨️ 입력·폼

정규식으로 URL을 검사하면 반드시 구멍이 납니다. 브라우저 내장 URL 파서로 쪼갠 뒤 항목별로 판정하고(https인가, 외부에서 닿는 호스트인가, 계정정보가 박혀 있나), 붙여넣기 잡음(앞뒤 공백·꺾쇠·따옴표)은 조용히 걷어냅니다.

결제가 승인·취소되면 이 주소로 POST를 보냅니다. https만, 외부에서 접근 가능한 주소만.
    주소를 입력하세요 
    const PRIVATE = [/^localhost$/, /\.local$/, /^127\./, /^10\./, /^192\.168\./, /^172\.(1[6-9]|2\d|3[01])\./, /^\[?::1\]?$/];
function checkWebhook(raw) {
  const clean = raw.trim().replace(/^[<"']+|[>"']+$/g, '');           // 붙여넣기 잡음
  const url = URL.parse?.(clean) ?? (() => { try { return new URL(clean) } catch { return null } })();
  if (!url) return { ok: false, issues: ['URL 형식이 아니에요'], suggest: /^[\w.-]+\.\w+/.test(clean) ? 'https://' + clean : null };
  const issues = [];
  if (url.protocol !== 'https:') issues.push('https만 받을 수 있어요');
  if (url.username || url.password) issues.push('주소에 아이디·비밀번호를 넣지 마세요');
  if (PRIVATE.some(r => r.test(url.hostname))) issues.push('외부에서 접근할 수 없는 주소예요');
  url.hash = '';                                                          // 서버로 안 가는 부분은 버림
  return { ok: issues.length === 0, issues, normalized: url.href };       // href: 호스트 소문자·기본 포트 제거
}
    입력값이 바뀌면 이전 테스트 결과는 무효 — "테스트 통과 = 지금 칸에 있는 이 주소"를 보장하려고 저장 버튼 조건을 정규화된 값에 묶습니다. 사설 IP 차단은 UX용 조기 경고이고, SSRF(서버가 내부망으로 요청을 보내게 만드는 공격) 방어는 반드시 서버에서 DNS 해석 후 다시 합니다.

    Intl.NumberFormat roundingMode·roundingIncrement — 10원 절사 표시를 toFixed 없이, 단 계산은 따로 🌀 트렌드·개념

    ES2023 NumberFormat v3로 들어온 옵션입니다. roundingMode는 반올림 방향 9종, roundingIncrement는 "몇 단위로 맞출지"(1·2·5·10·20·25·50·100…)를 정합니다. 숫자 → 문자열 표시에만 쓰고, 금액 계산 자체는 정수 연산으로 따로 합니다.
