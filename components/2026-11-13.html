📊 기간 비교 누적 차트 — "이번 달 vs 지난달"은 같은 일자까지만, 진행 중인 오늘은 따로 데이터·테이블·차트

월 중순에 "지난달 대비 −58%"가 뜨는 대시보드는 틀린 게 아니라 비교 대상이 틀린 겁니다. 12일치와 31일치를 비교했으니까요. 같은 일자까지 누적으로 겹쳐 그리고, 아직 끝나지 않은 오늘은 점선·빈 점으로 "진행 중"임을 보이게 합니다.

지난달은 회색 점선(배경), 이번 달은 진한 실선(주인공). 1~12일 음영 = 공정 비교 구간. 13일 구간은 점선 + 빈 원 = 집계 중. 색에 기대지 않도록 선 모양(실선/점선)과 직접 라벨로 구분.

// 같은 기간 비교: "완료된 마지막 날"까지만 양쪽을 자른다
const lastFullDay = isTodayIncluded ? today : today - 1;          // 13일 08시 → 12
const prevDays = daysInMonth(prevMonth);                          // 10월 31, 9월 30 …
const cut = Math.min(lastFullDay, prevDays);                      // 3/31 vs 2월(28) 대비
const curr = cumsum(thisMonth).at(cut - 1);
const prev = cumsum(lastMonth).at(cut - 1);
const pct  = prev ? (curr - prev) / prev : null;                  // prev=0이면 % 대신 '신규'
label = `1~${cut}일 기준 · 지난달 같은 기간 대비 ${fmtPct(pct)}`;

요일 효과가 큰 업종(주말 매출 0인 B2B 등)은 "일자 맞춤"보다 "요일 맞춤(지난달 같은 주차·같은 요일)"이 더 공정합니다. 11월 1일은 일요일, 10월 1일은 목요일이라 1~12일 안의 주말 수가 다를 수 있어요 — 카드 아래 보조 문구로 기준을 항상 써 두세요.

DEMO B — 새 거래 피드: 자동 끼워 넣기 vs 모아 두고 보여주기

    "바로 삽입"은 읽던 줄·누르려던 행이 아래로 밀립니다(레이아웃 이동). 목록 위쪽 버튼으로 모아 두면 사용자가 원할 때 반영 — 트위터/X식 "새 게시물 n개" 패턴.

    function applyUpdate(td, next, prev) {
  if (next === prev) return;
  td.querySelector('.num').textContent = fmt(next);
  td.querySelector('.dl').textContent =
    (next > prev ? '▲ +' : '▼ −') + fmt(Math.abs(next - prev));   // 색 말고 기호·숫자로도
  td.dataset.chg = next > prev ? 'up' : 'down';
  td.getAnimations().forEach(a => a.cancel());                     // 연속 변경 시 재시작
  clearTimeout(td._t);
  td._t = setTimeout(() => delete td.dataset.chg, 2400);
}
// 갱신 보류: 사용자가 멈췄거나, 표 위에 포인터/포커스가 있거나, 탭이 숨었을 때
const shouldHold = () => paused || tbl.matches(':hover, :focus-within') || document.hidden;

    WCAG 2.2.2(일시정지·정지·숨기기): 자동으로 5초 넘게 움직이거나 갱신되는 정보는 멈출 수단이 있어야 합니다. 갱신 주기가 사용자에게 중요한 정보라면 "일시정지" 버튼은 장식이 아니라 요건이에요.

    🌀 typed attr() — data-* 값을 CSS가 숫자·색으로 바로 읽기 트렌드·개념

    예전 attr()는 content에서 문자열로만 쓸 수 있었습니다. 새 문법 attr(data-v type(<number>), 0)은 속성값을 타입이 있는 값으로 파싱해서 width·color 같은 아무 속성에나 넣을 수 있어요. 막대 차트 폭을 style="--v:72" 대신 data-v="72" 하나로.

    DEMO — 슬라이더는 setAttribute('data-v')만 바꿉니다. 지원 브라우저면 CSS가 직접 읽고, 아니면 JS 폴백이 --v를 채웁니다

    "잘못된 값" 행: 파싱 실패 시 두 번째 인자(폴백 0, var(--brand))로 떨어지는 게 핵심 — 레이아웃이 깨지지 않습니다.

    .fill {
  width: calc(var(--v, 0) * 1%);                 /* 미지원 브라우저: JS가 --v를 채움 */
}
@supports (x: attr(x type(*))) {
  .fill {
    --v: attr(data-v type(<number>), 0);          /* "72" → 72, "abc" → 0 */
    background: attr(data-color type(<color>), var(--brand));
  }
}
/* 단위가 붙은 값은 단위 키워드로: attr(data-gap px, 8px) → "12" → 12px */
    지원 현황: Chromium 133+에서 타입 지정 attr()가 출시된 것은 확인됨. Firefox·Safari는 이 글 작성 시점 미지원 또는 진행 중으로 추정 — 실제 적용 전 caniuse에서 재확인하고, 위처럼 @supports + 폴백 필수.

    보안상 attr()로 읽은 값은 url() 안에 쓸 수 없도록 막혀 있습니다(속성값으로 외부 요청을 만드는 공격 방지, 스펙의 "attr-taint" 개념). 차트 폭·색·간격 같은 표현값에만 쓰세요.
