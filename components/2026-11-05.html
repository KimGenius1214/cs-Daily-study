🧭 커맨드 팔레트 — 메뉴를 찾아 다니지 말고 Ctrl+K로 이동·실행 내비게이션·탭

커맨드 팔레트는 검색창 하나로 "화면 이동"과 "작업 실행"을 모두 하는 오버레이입니다. 메뉴가 깊은 관리자 화면(거래·정산·가맹점·설정)에서 파워유저의 이동 비용을 크게 줄입니다.

A. 열어서 "정산", "환불", "ㅈㅅ" 등을 입력해 보세요 (↑↓ 선택, Enter 실행, Esc 닫기)

실행한 항목이 여기에 기록됩니다.

입력창은 combobox, 결과는 listbox입니다. 포커스는 입력창에 그대로 두고 aria-activedescendant로 "지금 선택된 항목"만 가리켜서, 타이핑을 멈추지 않고도 화살표로 고를 수 있습니다.

    // 핵심: 포커스는 input, 선택 표시는 aria-activedescendant
input.setAttribute('aria-activedescendant', items[i].id);

    초성 검색(ㅈㅅ → 정산)은 데모용으로 단순 구현했습니다. 실서비스에선 검증된 한글 검색 라이브러리나 서버 검색을 권합니다.

    🃏 순서 바꾸기 리스트 — 드래그만 믿지 말고 버튼·키보드로도, 맨 위가 "기본"이 되는 규칙 안내 카드·리스트

    결제수단 우선순위처럼 순서가 의미를 갖는 목록은 드래그앤드롭만 있으면 키보드·스크린리더 사용자가 못 씁니다. 같은 동작을 세 가지 경로(드래그, 위/아래 버튼, 키보드)로 모두 제공합니다.

    결제수단 우선순위 (핸들: 마우스 드래그 / 핸들에 포커스 후 Space로 집기 → ↑↓ → Space 놓기, Esc 취소)

      이동할 때마다 "토스페이, 3개 중 2번째로 이동했습니다"를 읽어 줍니다. 1번이 결제 시 기본 선택이므로 순서가 바뀌면 "기본 결제수단이 바뀝니다"를 눈에 보이게 알립니다.

      function move(from, to){
  const [it] = items.splice(from,1); items.splice(to,0,it);
  render(); live(`${it.name}, ${items.length}개 중 ${to+1}번째`);
}

      🌀 View Transitions — 정렬·필터로 DOM이 바뀔 때 요소가 "이동"하는 것처럼 보이게 트렌드·개념

      View Transitions API는 화면 상태가 바뀌기 전후를 브라우저가 스냅샷으로 찍어 자동으로 애니메이션해 주는 기능입니다. 같은 문서 안의 전환(document.startViewTransition)은 2025년 10월 Firefox 144 출시로 주요 브라우저 모두에서 쓸 수 있게 됐다고 web.dev가 발표했습니다(Baseline Newly available). 그래도 기능 감지 후 폴백은 필수입니다.

      정렬 기준을 바꿔 보세요. 카드가 제자리로 "날아가는지" 확인합니다.

      view-transition-name을 카드마다 고유하게 주면 브라우저가 "같은 카드"로 연결해 위치 이동을 애니메이션합니다. prefers-reduced-motion에서는 CSS로 애니메이션을 끕니다.
