🧭 하단 탭 바🃏 거래 금액 행🌀 scroll-target-group

하단 탭 바 — 라벨은 늘 보이게, 탭마다 스크롤을 기억하고, 지금 탭을 또 누르면 맨 위로 🧭 내비게이션·탭

모바일 앱의 최상위 이동은 하단 탭 바가 표준이 됐습니다. 차이는 디테일에서 납니다: 아이콘만 두지 않기, 탭을 오갈 때 보던 위치를 지키기, 이미 있는 탭을 다시 누르면 맨 위로 올리기, 홈 인디케이터(아이폰 하단 막대) 영역을 피하기.

휴대폰 안에서 직접 눌러 보세요 — 거래 탭에서 스크롤 → 정산 탭 → 다시 거래 탭(위치 유지) → 거래 탭 한 번 더(맨 위로)

피하기 아이콘만

아이콘만 쓰면 "지갑 모양이 정산인지 결제수단인지" 사용자가 추측해야 합니다. 라벨은 공간이 부족해도 짧게(2~3자) 줄여서라도 남기는 편이 낫습니다.

<nav class="tabbar" aria-label="주요 메뉴">
  <ul>
    <li><a href="/home" aria-current="page"><svg aria-hidden="true"…/><span>홈</span></a></li>
    <li><a href="/noti" aria-label="알림, 새 알림 3개">…<span class="badge" aria-hidden="true">3</span></a></li>
  </ul>
</nav>

/* viewport-fit=cover 메타가 있어야 env()가 0이 아님 */
.tabbar { position: fixed; inset: auto 0 0 0;
  padding-bottom: calc(6px + env(safe-area-inset-bottom)); }
.tabbar a { min-height: 48px; }                 /* 누르는 영역 */
.tabbar a[aria-current="page"] { color: var(--brand); font-weight: 800; }
main { padding-bottom: calc(64px + env(safe-area-inset-bottom)); } /* 마지막 줄이 바에 안 가리게 */
탭 바는 role="tablist"가 아닙니다. 화면 자체가 바뀌는 페이지 이동이라 <nav> 안의 링크 + aria-current="page"(지금 페이지라고 알려 주는 속성)가 맞습니다. tablist로 만들면 낭독기가 "탭 1/5"라고 읽고 화살표 키 이동을 기대하게 만듭니다.

거래 내역 금액 행 — 자릿수는 줄 맞추고, 마이너스는 기호와 말로, 취소는 줄긋기만으로 끝내지 않기 🃏 카드·리스트

금액 리스트는 "훑어 내려가며 비교하는" UI입니다. 숫자 폭이 들쭉날쭉하면 자릿수가 어긋나 1만 원과 10만 원이 비슷해 보이고, 하이픈 "-"은 낭독기가 건너뛰거나 "하이픈"으로 읽고, 취소선은 화면에서만 보입니다. 아래 체크를 하나씩 켜며 차이를 보세요.

    오늘 순합계 (취소 제외)
    행에 마우스를 올리거나 Tab으로 이동하면, 그 행의 마크업이 낭독기에 넘기는 텍스트(근사)를 보여 줍니다.
    —

    ③ 끄면 "-5,600원" — 하이픈(U+002D)은 숫자 앞에서 낭독기마다 "마이너스", "하이픈", 무음으로 갈립니다(추정, 낭독기·음성 설정마다 다름). 그래서 보이는 기호는 aria-hidden으로 숨기고 "출금 5,600원"처럼 말로 전달합니다. ④ 끄면 취소 건이 순합계에 섞여 보이는지 눈으로만 판단해야 합니다.

    <!-- 보이는 건 "−5,600원", 읽히는 건 "출금 5,600원" -->
<span class="amt">
  <span aria-hidden="true">−5,600원</span>   <!-- U+2212 MINUS SIGN -->
  <span class="sr-only">출금 5,600원</span>
</span>

<!-- 취소: 라벨로 상태를 말하고, 줄 그은 금액은 '원래 금액'이라고 읽힌다 -->
<span class="pill">결제 취소</span>
<span class="amt"><del><span class="sr-only">취소된 금액 </span>18,900원</del></span>

.amt { font-variant-numeric: tabular-nums; text-align: right; min-width: 9.5em; white-space: nowrap; }

// 포맷터: 부호는 따로, 숫자는 절대값으로
const nf = new Intl.NumberFormat('ko-KR');
const view = (n) => ({ visual: (n < 0 ? '−' : '+') + nf.format(Math.abs(n)) + '원',
                       spoken: (n < 0 ? '출금 ' : '입금 ') + nf.format(Math.abs(n)) + '원' });
    font-variant-numeric: tabular-nums는 숫자 글리프를 같은 폭으로 바꾸는 OpenType 기능입니다. 폰트가 이 기능을 갖고 있어야 효과가 있고, 일부 시스템 폰트는 원래 숫자 폭이 같아 차이가 작게 보일 수 있습니다(Pretendard·SF 계열은 기본이 비례폭이라 효과가 큽니다 — 추정). <del>은 많은 낭독기가 기본 설정에서 "삭제됨"을 읽지 않기 때문에(추정) sr-only 문구를 함께 둡니다.

    scroll-target-group과 :target-current — 목차 하이라이트(스크롤 스파이)를 CSS가 계산하게 🌀 트렌드·개념

    "지금 읽는 섹션을 목차에서 강조"하려면 지금까진 IntersectionObserver(요소가 화면에 들어왔는지 알려 주는 브라우저 API)로 JS를 짰습니다. 링크 목록 부모에 scroll-target-group: auto를 주면, 브라우저가 스크롤 위치에 맞는 링크 하나에 :target-current를 붙여 줍니다. 단, 화면 강조뿐이라 aria-current는 따로 챙겨야 합니다.

    개요

    정산은 결제 승인 금액에서 수수료와 환불을 뺀 금액을 가맹점 계좌로 보내는 과정입니다.

    이 문서는 정산 금액이 어떻게 정해지고 언제 들어오는지 설명합니다.

    정산 내역은 매일 오전에 갱신됩니다.

    수수료

    카드 결제는 업종·매출 구간에 따라 다른 수수료율이 적용됩니다.

    간편결제는 결제사별 수수료가 별도로 붙을 수 있습니다.

    수수료에는 부가세가 포함되어 표시됩니다.

    수수료율 변경은 다음 정산 주기부터 반영됩니다.

    정산 주기

    기본 주기는 영업일 기준 D+2입니다.

    공휴일이 끼면 다음 영업일로 밀립니다.

    주기 변경은 고객센터 요청으로 진행합니다.

    환불과 차감

    정산 후 환불이 발생하면 다음 정산 금액에서 차감됩니다.

    차감할 금액이 정산 금액보다 크면 차액이 이월됩니다.

    문의

    정산 관련 문의는 가맹점 관리자 > 고객센터에서 남겨 주세요.

    "끝 여백 두기"를 끄고 맨 아래까지 내려 보세요. 마지막 섹션(문의)이 짧으면 위쪽까지 올라오지 못해 목차에서 영영 강조되지 않습니다 — CSS 방식이든 JS 방식이든 같은 함정입니다.

    /* 1) 링크 목록의 부모를 '스크롤 대상 그룹'으로 */
.toc { scroll-target-group: auto; }

/* 2) 지금 스크롤 위치에 해당하는 링크 하나만 매칭 */
.toc a:target-current { color: var(--brand); border-left-color: var(--brand); font-weight: 700; }

/* 3) 미지원 브라우저용 폴백 — 같은 모양을 클래스로 */
@supports not (scroll-target-group: auto) {
  .toc a.is-current { color: var(--brand); border-left-color: var(--brand); font-weight: 700; }
}

// 폴백 JS + aria-current 동기화 (CSS 의사클래스는 접근성 트리에 안 올라감)
const io = new IntersectionObserver((entries) => {
  for (const e of entries) if (e.isIntersecting) setCurrent(e.target.id);
}, { root: scroller, rootMargin: '0px 0px -70% 0px' });
headings.forEach((h) => io.observe(h));
    지원 현황: Chrome 140 전후로 Chromium 계열에 들어온 것으로 알려져 있고(Chrome 가이드), Safari·Firefox는 이 글 작성 시점 기준 미지원으로 추정합니다. 그래서 실무에선 @supports로 감싸 진행적 향상(지원 브라우저에서만 더 좋아지고, 나머지는 기존 JS로 동작)으로 씁니다. 감지는 CSS.supports('scroll-target-group: auto').
