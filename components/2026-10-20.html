결제 수단

쿠폰 코드

 
dlg.addEventListener('click', e => { if (e.target === dlg) tryClose(); });   // 배경(::backdrop) 클릭
dlg.addEventListener('cancel', e => { if (dirty) { e.preventDefault(); confirmDiscard(); } }); // Esc
dlg.addEventListener('close', () => opener.focus());                          // 포커스 복귀(기본 동작이지만 명시)
showModal()은 배경을 inert(조작 불가) 처리하고 포커스를 가둡니다. 드래그는 보조 수단일 뿐 — 키보드·스크린리더 사용자는 "닫기" 버튼으로 닫아야 하므로 반드시 둡니다. 입력값이 있을 때만 닫기를 가로채세요(항상 막으면 짜증).

🔔 낙관적 업데이트 — 먼저 바꿔 보여주고, 실패하면 되돌리고 알리기 피드백·상태

optimistic update(서버 응답 전에 성공했다고 가정하고 UI를 먼저 바꾸는 방식)입니다. 설정 토글에 쓰면 빠르게 느껴지지만, 실패 시 롤백과 안내가 반드시 필요합니다.

오프라인입니다. 변경은 연결되면 다시 시도할 수 있어요.

저장됨: 꺼짐 (서버 기준)

    "서버가 실패하게 하기"를 켜고 토글해 보세요. 화면은 즉시 켜졌다가 600ms 뒤 되돌아가고 재시도 버튼이 나옵니다.

    const prev = state.enabled;
setEnabled(next);                          // 1) 먼저 반영
try { await save(next); }                  // 2) 서버 확인
catch { setEnabled(prev); showRetry(); }   // 3) 실패 → 원복 + 알림 + 재시도
    연타 대비: 진행 중에는 aria-busy로 표시하고 마지막 의도만 보내거나 요청을 직렬화하세요. 결제·잔액처럼 되돌릴 수 없는 값에는 낙관적 업데이트를 쓰지 않습니다 — 서버 확정 후 표시가 원칙입니다.

    🌀 CSS 앵커 포지셔닝 — 툴팁·팝오버를 JS 좌표 계산 없이 버튼에 붙이기 트렌드·개념

    anchor positioning(요소를 다른 요소 기준으로 CSS만으로 배치)입니다. 스크롤 영역 안에서 위로 공간이 모자라면 아래로 뒤집힙니다.

    지원 여부 확인 중…

    영역을 스크롤해 버튼 위치를 바꿔 보세요.

    수수료는 결제 금액의 2.9%이며 정산일에 차감됩니다.

    버튼에 마우스를 올리거나 포커스하면 표시, Esc로 닫기.

    .btn { anchor-name: --tip; }
.pop { position: fixed; position-anchor: --tip;
       position-area: top; position-try-fallbacks: flip-block; }
@supports not (anchor-name: --a) { /* JS getBoundingClientRect 폴백 */ }
    지원은 브라우저 버전에 따라 다르므로(추정: 최신 Chromium 계열 우선, 타 엔진은 버전 확인 필요) 기능 감지 후 폴백을 둡니다. 툴팁은 hover만 쓰지 말고 focus에도 열고 Esc로 닫게 하세요(WCAG 1.4.13).
